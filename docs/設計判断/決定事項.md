# 決定事項

- CLIの引数解析にはClickを使う。
- 標準のテキスト計測は`tiktoken:o200k_base`とし、`tokenizers`はextraで追加する。
- テキスト方式と画像方式は分け、`--text-tokenizer`と`--image-tokenizer`で指定する。
- 画像の既定方式は`gpt-5.6-style`とし、方式固有の計算を実装する。画像を任意にリサイズして数えない。
- `auto`は`tiktoken`を選び、導入済みでない方式へ黙って切り替えない。
- オンライン送信が必要な方式だけ`--allow-online`で許可する。MCPの接続許可とは分ける。
- 共通オプションはサブコマンドより前に置き、Gitの引数は専用パーサーで解釈する。
- `-p`は`stat`のファイル単位処理に使い、結果と診断の順序を決定的にする。
- ディレクトリの既定走査では`.gitignore`を反映し、`--ignore-gitignore`で無視する。
- `table`、`tree`、`json`は同じソート規則を使い、ディレクトリ合計をディレクトリ自身へ表示する。
- 警告とエラーは標準エラーへまとめ、計測結果と分ける。
- MCPはサーバーへ接続するクライアント機能だけを扱い、MCP記録ファイルの集計は扱わない。

## 不採用

- モデル名で方式を選ぶ`--model`は設けない。方式は`--text-tokenizer`または`--image-tokenizer`で指定する。
- 仕様にない`compare`コマンドは実装しない。
