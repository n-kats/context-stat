# 決定事項

- CLIの引数解析にはClickを使う。
- 標準のテキスト計測は`tiktoken:o200k_base`とし、`tokenizers`はextraで追加する。
- AnthropicのToken Count APIは`anthropic-api`バックエンドとしてextraで追加し、`--text-tokenizer`へClaude 5系のモデルIDを指定する。
- テキスト方式と画像方式は分け、`--text-tokenizer`と`--image-tokenizer`で指定する。
- 画像の既定方式は`gpt-5.6-style`とし、方式固有の計算を実装する。画像を任意にリサイズして数えない。
- `--image-tokenizer anthropic-api`は`--text-tokenizer`のモデルIDで画像をToken Count APIへ送る。
- `auto`は`tiktoken`を選び、導入済みでない方式へ黙って切り替えない。
- 外部通信が必要なトークン計測方式だけ、`--allow-online`で入力送信を許可する。バックエンドの導入・選択は別に指定する。
- 共通オプションはサブコマンドより前に置き、Gitの引数は専用パーサーで解釈する。
- `-p`は`stat`のファイル単位処理に使い、結果と診断の順序を決定的にする。
- ディレクトリの既定走査では`.gitignore`を反映し、`--ignore-gitignore`で無視する。
- `table`、`tree`、`json`は同じソート規則を使い、ディレクトリnodeに配下の対象の集計値を表示する。
- 警告とエラーは標準エラーへまとめ、計測結果と分ける。
- MCPはサーバーへ接続するクライアント機能だけを扱い、MCP記録ファイルの集計は扱わない。
- MCP接続は`--config`、Codexの`--codex-config`、またはStreamable HTTPの`--url`で指定する。Codex設定は`[mcp_servers.<名前>]`から接続情報を変換し、複数サーバーの場合は`--server`で選択する。直接URLの認証ヘッダーは`--header-from-env`で環境変数から読む。
- `mcp request`は結果状態を計測表の外側へ表示し、`-v`/`--verbose`指定時だけ返却結果本文を続けて表示する。画像のBase64はMIME typeと寸法の要約へ置き換える。`isError: true`は返却結果として保持し、診断と終了コードではエラー扱いにする。

## 不採用

- モデル名で方式を選ぶ`--model`は設けない。方式は`--text-tokenizer`または`--image-tokenizer`で指定する。
