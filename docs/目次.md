# ディレクトリ・ファイル一覧

## ルート

`src/context_stat/cli.py`: ClickによるCLIとコマンド定義。
`src/context_stat/output.py`: table、tree、JSONの出力。

`src/context_stat/domain/content.py`: 計測対象と入力事実。
`src/context_stat/domain/errors.py`: ドメインエラー。
`src/context_stat/domain/measurement.py`: 計測項目と計測条件。
`src/context_stat/domain/parallel.py`: 順序を保持した並列処理。
`src/context_stat/domain/report.py`: 計測レポート。
`src/context_stat/domain/service.py`: テキスト・画像の計測サービス。
`src/context_stat/adapters/`: 外部入力・ライブラリとの接続。
`src/context_stat/adapters/__init__.py`: アダプターパッケージ定義。
`src/context_stat/adapters/filesystem.py`: ファイル列挙、UTF-8、バイナリ、Gitignore判定。
`src/context_stat/adapters/git.py`: Git差分の引数解析、実行、ファイル別patch分割。
`src/context_stat/adapters/image.py`: 画像属性と画像トークン方式。

`src/context_stat/adapters/process.py`: ファイルごとのコマンド実行、上限、タイムアウト。
`src/context_stat/adapters/templating.py`: Jinjaレンダリング。
`src/context_stat/adapters/token.py`: tiktokenとtokenizersのバックエンド。

## ファイルの探し方

- 使い方は`docs/手順/`から探す。
- 実装の挙動を確認するときは`docs/現状/`と`docs/仕様/`を参照する。
- 実装の責務や配置を確認するときは`docs/設計/`と`src/context_stat/`を参照する。
- 判断理由を確認するときは`docs/設計判断/`と`docs/外部参照/`を参照する。
- 作業中のTODOや検討ログは`_worklist/`と`_notes/`にあるが、成果物の構造一覧には含めない。
