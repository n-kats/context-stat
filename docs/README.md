# ドキュメント

文書は用途ごとに分けます。現行実装の利用方法は`手順`、判断の基準は`仕様`、実装の構成は`設計`を参照してください。物理的な配置は`目次.md`を正のソースとします。

- [`README.md`](README.md): docs全体の入口
- [`目次.md`](目次.md): 実装系・文書系の物理構成
- [`アイデア/`](アイデア/README.md): 採用前の案
- [`仕様/`](仕様/README.md): 実装が満たす機能仕様
- [`外部参照/`](外部参照/README.md): 外部サイトや公式資料の参照ログ。現行仕様ではない
- [`手順/`](手順/README.md): 利用・検証の手順
- [`現状/`](現状/README.md): 仕様との差分、未完了事項、確認結果
- [`規約/`](規約/README.md): 文書・実装の記述規約
- [`計画/`](計画/README.md): 今後の作業
- [`設計/`](設計/README.md): レイヤー、責務、配置
- [`設計判断/`](設計判断/README.md): 採用した方針と却下した案

仕様と実装が異なる場合は、独断で補正せず、`現状`と作業ログに差異を記録してから仕様を更新します。
