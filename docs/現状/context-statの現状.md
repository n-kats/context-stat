# context-statの現状

この文書は開発途中の記録であり、`docs/仕様/`に対する未完了・部分実装・確認待ちだけを記載する。実装済みの機能一覧や使い方は、[仕様](../仕様/context-stat機能仕様.md)と[手順](../手順/context-statを使う.md)を参照する。

## 仕様との差分

| 項目 | 現状 | 残っている差分 |
| --- | --- | --- |
| 画像方式 | `gpt-5.6-style`と`anthropic-api`を実装済み。その他の方式は未実装 | 方式ごとの公式根拠、上限、正規化、テストが必要 |
| 論理レイヤーの分離 | 一部の論理責務が関数・アダプターのままで、共通インターフェースへ分離されていない | 分離する場合の境界と移行手順が未確定 |
