# 現状

`docs/現状/`は、現行仕様に対してまだ残っている開発上の差分を記録する場所です。

## 記載するもの

- 仕様に対する未実装の機能
- 部分実装や仕様との差分
- 判断や追加確認が必要な未確定事項

## 記載しないもの

- 実装済み機能の一覧や利用方法
- 将来の作業計画
- テスト、lint、format、lockなどの検証結果
- 設計上の責務や採用理由の詳細

それぞれの内容は、実装済み機能と利用方法は[仕様](../仕様/context-stat機能仕様.md)と[手順](../手順/context-statを使う.md)、将来の作業は[計画](../計画/README.md)、検証結果は`_worklist/`、設計と判断理由は[設計](../設計/README.md)と[設計判断](../設計判断/README.md)に記載します。

## 更新ルール

- 仕様との差分が発生したら、このディレクトリへ項目を追加または更新する。
- 差分が解消したら、このディレクトリから該当項目を削除する。
- 完了した内容を履歴として残す場所にはしない。履歴は`_worklist/`に残す。
- 仕様と実装が異なる場合は、独断で仕様を変更せず、差分として記録してから判断する。
