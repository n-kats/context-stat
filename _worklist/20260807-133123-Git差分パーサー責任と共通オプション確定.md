## 決定事項

- `--model`、`--backend`、`--tokenizer`、`--allow-online`、`--output-format`などの共通オプションは、サブコマンドより前に置く。
- `context-stat git diff`の後ろには、Git diffと同じ引数構文を置く。
- Git diffの引数を未解釈のままGitへ渡さない。
- Git差分専用パーサーが、Gitオプション、revision、`--`、pathspecを解釈・検証・正規化する。
- 専用パーサーの構造化結果からGit実行用argvを生成する。
- revisionの存在やリポジトリ状態など、Git自身が検証する事項はGitの実行結果として扱う。
- チャット形式やAPI固有のラッパーを追加せず、生テキストをトークン計測する。
- 出力は人間向け形式を既定とし、`--output-format json`で機械可読形式を選択する。

## 確認手順

- `context-stat --model gpt-5.6 --backend tiktoken git diff branch branch -- file`で、共通オプションとGit引数が別々に解釈されることを確認する。
- `context-stat git diff`で比較対象未指定のGit diffを実行できることを確認する。
- Git diffの`--`がcontext-statの区切りではなく、Gitのrevision/pathspec区切りとして扱われることを確認する。
- 未知のGit引数がGitへそのまま渡らず、context-statのエラーになることを確認する。
- トークン数にチャットラッパーやAPI固有の追加文字列が含まれないことを確認する。
