# MCP一覧表示の情報量改善

## 目的

`mcp list`のtable出力で、内部インデックスではなくMCPの実際の名前を表示し、一覧定義の説明やリソースURIを確認できるようにする。

## 決定事項

- ツールとプロンプトは`name`を表示名にする。
- リソースは`name`を優先し、なければ`uri`を表示名にする。
- 説明は一覧項目に存在する場合だけtableへ表示する。
- リソースURIはリソース一覧に存在する場合だけtableへ表示する。
- スキーマ本文はtableへ展開せず、従来どおり構造化payloadとトークン計測値で確認できるようにする。

## 未決事項

- スキーマ内の各プロパティをtableで個別表示するかは、今回の変更対象に含めない。

## 確認手順

- MCP一覧のtableとJSONで、項目名が`tools[0]`ではなく実際の名前になることを確認する。
- 説明とリソースURIの表示を単体テストで確認する。
- `uv run pytest -q`
- `uv run ruff check .`
- `uv run ruff format --check .`
- `uv lock --check`
- `git diff --check`

## 結果

- 一覧項目の表示名を、ツール・プロンプトは`name`、リソースは`name`または`uri`にした。
- tableに説明を追加し、リソースでは項目名と異なるURIも追加表示するようにした。
- JSONの`metadata.mcp_definition`に一覧定義全体を保持するようにした。
- `uv run pytest -q`: 75 passed
- `uv run ruff check .`: 問題なし
- `uv run ruff format --check .`: 問題なし
- `uv lock --check`: 問題なし
- `git diff --check`: 問題なし
