## 決定事項

- `--codex-config FILE`はCodex設定内の`mcp_servers`を読む。
- 有効な接続設定が1つなら`--server`なしで選択する。
- 複数ある場合は`--server NAME`を必須にする。
- Codexの`enabled = false`は選択対象から除外する。
- CodexのOAuth保存情報、ChatGPTセッション認証、ツール許可設定は再利用しない。
- Codex設定の接続情報だけをcontext-statの`McpServerConfig`へ変換する。
- `--config`、`--codex-config`、`--url`は同時に指定しない。

## 確認手順

- stdioとStreamable HTTPのCodex TOMLを単体テストで検証する。
- 複数サーバー選択、無効サーバー、認証情報の変換を検証する。
- `uv run pytest -q`
- `uv run ruff check .`
- `uv run ruff format --check .`
- `uv lock --check`
- `git diff --check`

## 結果

- `--codex-config FILE`でCodexの`[mcp_servers.<名前>]`を読み取れるようにした。
- 有効なサーバーが1つなら自動選択し、複数なら`--server NAME`を要求する。
- stdioとStreamable HTTPの接続情報、HTTPヘッダー、Bearer token環境変数を変換する。
- OAuth保存情報、ChatGPTセッション認証、ツール許可設定は再利用しない。
- `uv run pytest -q`: 79 passed
- `uv run --extra tokenizers pytest -q`: 79 passed
- `uv run ruff check .`: 問題なし
- `uv run ruff format --check .`: 問題なし
- `uv lock --check`: 問題なし
- `git diff --check`: 問題なし
