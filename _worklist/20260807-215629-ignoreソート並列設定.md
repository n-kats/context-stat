## 決定事項

- `.gitignore`のパターンは変更せず、ignore判定側でシンボリックリンクを解決しない。
- `--sort path`を既定とし、`--order asc`を既定とする。
- `--sort`で指定した値が同じ階層の兄弟の並び順を決め、treeにも適用する。
- `-p, --parallel`はルートオプションとしてサブコマンドより前に置く。statの並列ワーカー数を指定し、既定値は1、0はCPU数による自動設定とする。
- 並列処理の結果と警告の順序は、ソート後の入力順に合わせて決定的にする。
- treeの枝はRichで描画し、対象行は`path [value]`の形式にする。推定値は対象行へ付けず、`measurement-estimated`警告へ集約する。

## 実施結果

- `Path.resolve()`をignore判定に使わないようにし、`.venv/bin/python`のようなシンボリックリンク先がリポジトリ外でも`.gitignore`へ一致するようにした。
- `--sort path`と`--order asc`を既定にし、指定した計測値による昇順・降順をtable、JSON、treeへ適用した。treeの各階層も同じ比較規則で並べた。
- `-p N stat` / `--parallel N stat`でファイル収集、計測、ファイル単位コマンドを順序保持のまま並列化した。`0`はCPU数を使う。
- RichのTreeで`├──`、`└──`、`│`を描画し、推定値の注記はtreeの各行から除去した。推定値は`measurement-estimated`として標準エラーへ1件に集約した。
- Richを標準依存へ追加し、`uv lock`でロックファイルを更新した。
- `uv run pytest`は41件通過した。`uv run ruff check .`、`uv run ruff format --check .`、`uv lock --check`を通過した。
- `uv tool install . --force --no-cache`後の実行ファイルでも標準罫線と集約警告を確認した。
